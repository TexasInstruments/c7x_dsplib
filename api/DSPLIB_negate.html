    DSPLIB_negate¶

    group DSPLIB_negate

    Kernel for negating the values contained in input data vector.

    • The kernel supports int8_t, int16_t, and int32_t datatypes.

    Functions¶

    int32_t DSPLIB_negate_getHandleSize(DSPLIB_negate_InitArgs *pKerInitArgs)¶

    This is a query function to calculate the size of internal handle.

    Remark

    Application is expected to allocate buffer of the requested size and provide it as input to other functions requiring it.

    Parameters:¶
    DSPLIB_negate_InitArgs *pKerInitArgs¶

    [in] : Pointer to structure holding init parameters

    Returns:¶

    Size of the buffer in bytes

    DSPLIB_STATUS DSPLIB_negate_init(DSPLIB_kernelHandle handle, DSPLIB_bufParams1D_t *bufParamsIn, DSPLIB_bufParams1D_t *bufParamsOut, const DSPLIB_negate_InitArgs *pKerInitArgs)¶

    This function should be called before the DSPLIB_negate_exec function is called. This function takes care of any one-time operations such as setting up the configuration of required hardware resources such as the MMA accelerator and the streaming engine. The results of these operations are stored in the handle.

    Remark

    Application is expected to provide a valid handle.

    Parameters:¶
    DSPLIB_kernelHandle handle¶

    [in] : Active handle to the kernel

    DSPLIB_bufParams1D_t *bufParamsIn¶

    [in] : Pointer to the structure containing dimensional information of input buffer

    DSPLIB_bufParams1D_t *bufParamsOut¶

    [out] : Pointer to the structure containing dimensional information of ouput buffer

    const DSPLIB_negate_InitArgs *pKerInitArgs¶

    [in] : Pointer to the structure holding init parameters

    Returns:¶

    Status value indicating success or failure. Refer to DSPLIB_STATUS.

    DSPLIB_STATUS DSPLIB_negate_init_checkParams(DSPLIB_kernelHandle handle, const DSPLIB_bufParams1D_t *bufParamsIn, const DSPLIB_bufParams1D_t *bufParamsOut, const DSPLIB_negate_InitArgs *pKerInitArgs)¶

    This function checks the validity of the parameters passed to DSPLIB_negate_init function. This function is called with the same parameters as the DSPLIB_negate_init, and this function must be called before the DSPLIB_negate_init is called.

    Remark

    None

    const DSPLIB_bufParams1D_t *bufParamsOut¶

    [out] : Pointer to the structure containing dimensional information of output buffer

    const DSPLIB_negate_InitArgs *pKerInitArgs¶

    [in] : Pointer to the structure holding init parameters

    Returns:¶

    Status value indicating success or failure. Refer to DSPLIB_STATUS.

    DSPLIB_STATUS DSPLIB_negate_exec_checkParams(DSPLIB_kernelHandle handle, const void *pIn, const void *pOut)¶

    This function checks the validity of the parameters passed to DSPLIB_negate_exec function. This function is called with the same parameters as the DSPLIB_negate_init, and this function must be called before the DSPLIB_negate_init is called.

    Remark

    None

    Parameters:¶
    DSPLIB_kernelHandle handle¶

    [in] : Active handle to the kernel

    const void *pIn¶

    [in] : Pointer to the structure input buffer

    const void *pOut¶

    [out] : Pointer to the output buffer

    Returns:¶

    Status value indicating success or failure. Refer to DSPLIB_STATUS.

    DSPLIB_STATUS DSPLIB_negate_exec(DSPLIB_kernelHandle handle, void *pIn, void *pOut)¶

    This function is the main kernel compute function.

    Please refer to details under DSPLIB_negate_exec

    Remark

    Before calling this function, application is expected to call DSPLIB_negate_init and DSPLIB_negate_exec_checkParams functions. This ensures resource configuration and error checks are done only once for several invocations of this function.

    Assumptions:

    • None

    Performance Considerations:

    For best performance,

    • the input and output data buffers are expected to be in L2 memory

    • the buffer pointers are assumed to be 64-byte aligned

    Parameters:¶
    DSPLIB_kernelHandle handle¶

    [in] : Active handle to the kernel

    void *pIn¶

    [in] : Pointer to buffer holding the input data

    void *pOut¶

    [out] : Pointer to buffer holding the output data

    Returns:¶

    Status value indicating success or failure. Refer to DSPLIB_STATUS.
