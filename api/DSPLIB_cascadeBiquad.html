    DSPLIB_cascadeBiquad¶

    group DSPLIB_cascadeBiquad

    Kernel for multichannel multistage cascade on input data.

    The kernel supports computation of biquads of a vector of several inputs in one kernel call.

    Enums¶

    enum DSPLIB_biquadForm¶

    Enumeration for biquad realization form.

    This enumeration defines the type of biquad realization.

    • DSPLIB_BIQUAD_TIF : TI Form

    • DSPLIB_BIQUAD_DF1 : Direct Form I

    • DSPLIB_BIQUAD_DF2 : Direct Form II

    • DSPLIB_BIQUAD_TDF2 : Transposed Direct Form II

    Values:

    enumerator DSPLIB_BIQUAD_TIF¶

    TI Form.

    enumerator DSPLIB_BIQUAD_DF1¶

    Direct Form I.

    enumerator DSPLIB_BIQUAD_DF2¶

    Direct Form II.

    enumerator DSPLIB_BIQUAD_TDF2¶

    Transposed Direct Form II.

    DSPLIB_STATUS DSPLIB_cascadeBiquad_get_coefficientsBufferDesc(uint32_t dataType, uint32_t numStages, uint32_t numChannels, uint32_t biquadForm, uint32_t enableNChCoeffs, DSPLIB_bufParams2D_t *pBufParamsFilterCoeffOpt)¶

    Get coefficient buffer descriptor for optimized cascade biquad.

    Remark

    The application is expected to allocate the buffer using the dimension information in the returned buffer descriptor.

    Parameters:¶
    uint32_t dataType¶

    [in] : Type of the data in the buffer. Supported data types are:

    • DSPLIB_FLOAT32

    uint32_t numStages¶

    [in] : Number of cascade stages

    uint32_t numChannels¶

    [in] : Number of channels

    uint32_t biquadForm¶

    [in] : Type of the biquad realization. Supported forms are:

    • DSPLIB_BIQUAD_TIF

    • DSPLIB_BIQUAD_DF1

    • DSPLIB_BIQUAD_DF2

    • DSPLIB_BIQUAD_TDF2

    uint32_t enableNChCoeffs¶

    [in] Flag to enable per channel filter coefficients.

    • 0 => same coefficients for all channels

    • 1 => different coefficients for each channel

    DSPLIB_bufParams2D_t *pBufParamsFilterCoeffOpt¶

    [inout] : Pointer to the buffer descriptor.

    Status value indicating success or failure. Refer to DSPLIB_STATUS.

    DSPLIB_STATUS DSPLIB_cascadeBiquad_exec(DSPLIB_kernelHandle handle, void *pIn, void *pFilterCoeff, void *pFilterVar, void *pOut)¶

    This function is the main kernel compute function.

    Please refer to details under DSPLIB_cascadeBiquad

    Remark

    Before calling this function, application is expected to call DSPLIB_cascadeBiquad_init and DSPLIB_cascadeBiquad_exec_checkParams functions. This ensures resource configuration and error checks are done only once for several invocations of this function.

    Assumptions:

    • None

    Performance Considerations:

    For best performance,

    • the input and output data buffers are expected to be in L2 memory

    • the buffer pointers are assumed to be 64-byte aligned

    Parameters:¶
    DSPLIB_kernelHandle handle¶

    [in] : Active handle to the kernel

    void *pIn¶

    [in] : Pointer to buffer holding the input data

    void *pFilterCoeff¶

    [in] : Pointer to buffer holding the filter coefficient data

    void *pFilterVar¶

    [in] : Pointer to buffer holding the filter state variable data

    void *pOut¶

    [out] : Pointer to buffer holding the output data

    Returns:¶

    Status value indicating success or failure. Refer to DSPLIB_STATUS.
